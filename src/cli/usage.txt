   O    O      tetron-browser is a Chromium based browser for the terminal,
    \  /       a maintained continuation of Carbonyl.
O —— Cr —— O   In addition to the following options,
    /  \       it also supports most Chromium options.
   O    O      

Usage: tetron-browser [options] [url]

Options:
    -f, --fps=<fps>            set the maximum number of frames per second (default: 60)
    -z, --zoom=<zoom>          set the zoom level in percent (default: 100)
    -b, --bitmap               render text as bitmaps
    -d, --debug                enable debug logs
    -h, --help                 display this help message
    -v, --version              output the version number

Navigation bar:
    [❮][❯] back, forward   [↻] reload   [⌂] home page
    [☆] bookmark this page (adds it to the folder "Links"; [★] click again to remove)
    [−][100%][+] zoom out, reset, in (a new page starts at 100%)
    Click the address to edit it, Enter to go.
    Sideways: tilt the wheel or swipe sideways, Shift+wheel, the arrow keys, or click
    the bar at the bottom of a wide page (dragging its handle does not work yet).

Home page:
    With no url it opens the home page; the [⌂] button in the bar goes there.
    The first of these is used:
      TETRON_BROWSER_HOME=<url or path>    environment variable
      ~/.config/tetron-browser/home        file whose first line is a url or path
      ~/.config/tetron-browser/bookmarks.html   your bookmarks
    (~/.config is $XDG_CONFIG_HOME when set.) [☆] adds to the same bookmarks file.
    It is a Netscape bookmark file: edit it by hand, or import it into another
    browser. Created the first time from tetron-wm's older bookmarks.txt when that
    exists, else from a default list. tetron-wm's Start Page shows the same file.
